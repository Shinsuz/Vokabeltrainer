# Madina Book 1 – Trainer

Ein Lern-Trainer für **Madina Book 1** (Arabisch).

> **Hinweis zum Zugriff:** Der Trainer ist frei online erreichbar und darf von allen genutzt werden.

> 🚧 **Status: in Arbeit.** Der Kurs läuft noch, daher sind die Vokabeln und Lektionen noch nicht vollständig. Der Trainer wird fortlaufend mit dem Kursfortschritt erweitert.

## Inhalt

### 📚 Vokabeltrainer
- Vokabeln der Lektionen, lektionsweise gegliedert
- Grammatikalische Begriffe als eigene Lektion im Vokabelbereich (teils aus dem Buch, teils vom Lehrer)

### ✏️ Grammatiktrainer
- Ebenfalls lektionsbasiert aufgebaut

### 🔤 Pluraltrainer
- Übungen zu den Pluralformen: gesunder Plural, gebrochener Plural und weitere
